Privacy Policy

Alti

How Alti handles user information.

Effective: November 23, 2026Updated: November 23, 2026

1. Overview

Alti is an Android desktop mascot application provided by Lab 3776. It offers chat with a character, comments while the screen is shared, drawing, and related features. Lab 3776 does not operate a server for this application and does not receive user data from it. The application contains no advertising and no developer analytics.

2. Processing routes (local / API)

Alti has two AI processing routes, selectable in Settings. With the local route (the default), the AI model LFM2.5-VL-450M runs on the device. Conversation text and images are processed on the device and are not sent anywhere by the application. On first use, the model files are downloaded from Liquid AI's official distribution on Hugging Face; this download connects to the distributor's servers.

With the optional API route, if the user configures their own Google Gemini API key, conversation text — and, while screen sharing is on or when an image is involved, that image — is sent to Google's Gemini API and handled under Google's terms. The API key is stored only on the device in storage encrypted with an Android Keystore-protected key, and is used solely for Gemini API requests.

3. Screen sharing and text recognition

Screen sharing runs only while the user has started sharing. While sharing, the application captures screen frames to generate the character's comments. Text on the screen is read with Google ML Kit Text Recognition, which runs on-device.

Google's ML Kit disclosure states that the SDK may collect device/app information, per-installation identifiers, performance and API metrics, feature/event information, and error codes for diagnostics and usage analytics. Google states that this data is encrypted in transit and is not shared by ML Kit with third parties.

ML Kit data disclosure

4. Data stored on the device

Conversation history is stored in an on-device database. Conversation history and the model files are kept in an area excluded from Android backup. The character's memory data (such as conversation summaries) is stored in an on-device database and can be erased from Settings. App settings, such as the route selection and mascot behavior switches, are stored on the device.

5. Permissions

Internet access is used to download the model files and, on the API route, to connect to the Gemini API. Display over other apps is used for the bubble. A foreground service keeps the bubble and screen sharing running. Notifications announce the character's messages.
