# プライバシーポリシー (Privacy Policy)

**制定日: 2026年11月23日**  
**最終改定日: 2026年11月23日**

## 1. 概要

「Alti」（以下、本アプリ）は、Lab 3776（以下、開発者）が提供するAndroid向けデスクトップマスコットアプリです。キャラクターとのチャット、画面共有中のコメント、描画などの機能を提供します。

本ポリシーは、本アプリにおける利用者情報の取り扱いについて説明します。開発者は、本アプリのためのサーバーを運用しておらず、利用者のデータを開発者のサーバーへ送信することはありません。本アプリに広告および開発者によるアクセス解析は含まれていません。

## 2. 処理経路（ローカル／API）

本アプリのAI処理には2つの経路があり、設定で切り替えることができます。

### 2.1 ローカル経路（既定）

AIモデル「LFM2.5-VL-450M」が端末上で動作します。会話文および画像は端末内で処理され、本アプリが外部へ送信することはありません。

モデルファイルは、初回利用時に Liquid AI の公式配布元（Hugging Face）からダウンロードされます。このダウンロードでは、配布元のサーバーへ接続要求が送られます。

### 2.2 API経路（任意）

利用者が自身の Google Gemini API キーを設定した場合、会話文、および画面共有中や画像を扱う場合にはその画像が、Google の Gemini API へ送信されます。送信されたデータの取り扱いは Google の規約に従います。

APIキーは、Android Keystore で保護された暗号化ストレージに端末内でのみ保存され、Gemini API へのリクエスト以外に使用されません。

## 3. 画面共有と文字認識

画面共有は、利用者が共有を開始したときにのみ動作します。共有中、本アプリは画面のフレームを取得し、キャラクターのコメント生成に使用します。画面内の文字の読み取りには Google ML Kit Text Recognition を使用し、認識は端末上で行われます。

GoogleのML Kit Data Safety資料では、ML Kit Android SDKは診断・利用状況分析のため、端末情報、アプリ情報、インストール単位の識別子、性能指標、API設定、入出力サイズ、機能バージョン、イベント種別、エラーコード等を収集する場合があると説明されています。Googleは、これらのデータをHTTPSで暗号化して送信し、第三者へ共有しないと説明しています。

詳細:

- [ML Kit - Google Play data disclosure](https://developers.google.com/ml-kit/android-data-disclosure)

## 4. 端末内に保存されるデータ

- 会話履歴：端末内のデータベースに保存されます。会話履歴とモデルファイルは、Androidのバックアップ対象外の領域に保存されます。
- 記憶データ：キャラクターの記憶（会話の要約等）は端末内のデータベースに保存され、設定から消去できます。
- 設定情報：経路の選択、マスコット動作のON／OFF等は端末内に保存されます。

## 5. 権限

本アプリは以下の権限を使用します。

- インターネット：モデルファイルのダウンロード、およびAPI経路での Gemini API への接続のため。
- 他のアプリの上に重ねて表示：バブル表示のため。
- フォアグラウンドサービス：バブル表示と画面共有を継続するため。
- 通知：キャラクターからの発話を知らせるため。
